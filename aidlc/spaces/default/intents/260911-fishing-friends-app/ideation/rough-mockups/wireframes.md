# Wireframes — 友達と使う釣りアプリ（ラフ画面案）

## Sources

- 上流資料: `../intent-capture/intent-statement.md`（intent-statement: 次の釣行で自分のスマホで釣果を見せる）、`../scope-definition/scope-document.md`（scope-document: 最小範囲＝釣果の登録と一覧、スマホ）、`../scope-definition/intent-backlog.md`（intent-backlog: PU-1 が Must、PU-2〜PU-5 は後）
- 本工程の確認済み回答: `rough-mockups-questions.md` の Q1〜Q7（本文中では `[Q<n>]` で参照）

## Overview（この資料の範囲）

intent-backlog の PU-1「釣果の登録と一覧」を構成する3画面（一覧／登録／詳細）をラフに描く。scope-document の最小範囲に合わせ、スマホの縦画面を前提にする。PU-2 以降（グループ・タイムライン・地図・位置共有）は、この段階では入口の置き場所だけを想定する。見た目の指針は「シンプルで見やすい」以外に指定なし。[Q5]

凡例: `[ボタン]`、`( )` はタップ領域、`...` は省略。

## Information Architecture（画面の構成）

```
[S1 釣果の一覧]  ← アプリの入口 [Q1]
   |-- (＋) --> [S2 釣果の登録] --保存--> S1 に戻る（新しい1件が先頭に）
   |-- (カードをタップ) --> [S3 釣果の詳細]（見るだけ）[Q7]
   `-- (後で追加: グループ／タイムライン／地図の入口)
```

## S1. 釣果の一覧（入口）

アプリを開いたときに最初に見える画面。新しい釣果が上。写真が大きいカードが縦に並ぶ。[Q1][Q3]

### 通常状態（釣果あり）

```
+----------------------------+
| 釣果                        |  <- ヘッダー（h1）
+----------------------------+
| +------------------------+ |
| |                        | |
| |      [写真]            | |  <- カード1（最新）
| |                        | |
| +------------------------+ |
| | アジ  25cm             | |  <- 魚種・サイズ
| | 大黒海釣り施設  9/13   | |  <- 場所・日付
| +------------------------+ |
| +------------------------+ |
| |                        | |
| |      [写真]            | |  <- カード2
| |                        | |
| +------------------------+ |
| | メバル  18cm           | |
| | 本牧  9/13             | |
| +------------------------+ |
|            ...             |
|                    (  +  ) |  <- 登録ボタン（右下・大きめ）
+----------------------------+
```

- カード1枚 = 釣果1件。写真／魚種／サイズ・重さ／場所を表示（scope-document の記録項目）。
- 右下の (＋) が唯一の主要操作。タップで S2 へ。[Q1]
- カード全体がタップ領域。タップで S3 へ。[Q7]

### 空の状態（初回・釣果0件）

```
+----------------------------+
| 釣果                        |
+----------------------------+
|                            |
|                            |
|      まだ釣果がありません   |
|                            |
|   最初の1匹を記録しましょう |
|                            |
|      [ 釣果を登録する ]     |  <- 中央に大きなボタン
|                            |
|                    (  +  ) |
+----------------------------+
```

### その他の状態

- 読み込み中: カードの形の灰色の枠（スケルトン）を2〜3枚表示。
- 1件だけ: カード1枚と余白。空の状態の文言は出さない。
- 多数（100件以上）: 下へスクロールで続きを読み込む。上部に「上へ戻る」は不要（最小範囲）。
- 長い文字: 魚種・場所は1行で省略（`...`）し、全文は S3 で見せる。
- エラー（読み込み失敗）: 「釣果を読み込めませんでした [再読み込み]」を一覧の位置に表示。

### アクセシビリティ

- 見出し: 「釣果」= h1。カード内の魚種 = h2。ランドマーク: header（タイトル）／main（一覧）。キーボード・スイッチ操作の入口: 最初のフォーカスは (＋) ボタン。カードは1枚ずつフォーカスでき、Enter で S3。写真には「アジ 25cm の写真」のような代替テキストを付ける。タップ領域は 44px 以上。

## S2. 釣果の登録

1画面で写真・魚種・サイズ・重さ・場所をまとめて入力する。[Q2] 場所は釣り場の名前を文字で入力。[Q4]

### 通常状態

```
+----------------------------+
| < 戻る    釣果を登録        |  <- ヘッダー（h1）。「戻る」で S1 へ
+----------------------------+
| 写真                        |
| +------------------------+ |
| |   [ カメラで撮る ]      | |  <- 撮影 or 端末の写真から選ぶ
| |   [ 写真を選ぶ ]        | |
| +------------------------+ |
|                            |
| 魚種                        |
| [ 例: アジ               ] |  <- 文字入力
|                            |
| サイズ (cm)   重さ (g)      |
| [   25   ]   [   120   ]   |  <- 数値入力（横並び）
|                            |
| 場所                        |
| [ 例: 大黒海釣り施設      ] |  <- 文字入力
|                            |
|                            |
| [        保存する         ] |  <- 主要ボタン（画面下・幅いっぱい）
+----------------------------+
```

- 「保存する」で S1 に戻り、登録した1件が先頭に表示される。
- 写真を選ぶと、ボタンの位置にプレビューが出て「変更」に切り替わる。

### その他の状態

- 入力エラー: 保存時に未入力・不正値があれば、その項目の直下に文言で示す（例: 「サイズは数字で入力してください」）。必須項目の扱いは要件整理で決める（下記 Assumptions）。
- 保存中: 「保存する」を「保存中...」にして二重送信を防ぐ。
- 保存失敗: 画面上部に「保存できませんでした。もう一度お試しください」と表示し、入力内容は保持する。
- 戻る（未保存）: 入力があれば「入力を破棄しますか？」の確認を出す。

### アクセシビリティ

- 見出し: 「釣果を登録」= h1。各項目にラベル（写真／魚種／サイズ／重さ／場所）を入力欄の上に表示。ランドマーク: header／main（フォーム）。キーボード操作の入口: 最初のフォーカスは「カメラで撮る」。Tab 順は上から下。数値欄は数字キーボードを出す。

## S3. 釣果の詳細（見るだけ）

一覧のカードをタップして開く。大きな写真と項目の確認のみ。編集・削除は最小範囲に含めない。[Q7]

### 通常状態

```
+----------------------------+
| < 戻る                      |  <- 「戻る」で S1 へ
+----------------------------+
| +------------------------+ |
| |                        | |
| |                        | |
| |       [大きな写真]      | |
| |                        | |
| |                        | |
| +------------------------+ |
|                            |
| アジ                        |  <- 魚種（h1）
| 25cm / 120g                |  <- サイズ・重さ
| 大黒海釣り施設              |  <- 場所
| 2026/9/13                  |  <- 日付
|                            |
|                            |
+----------------------------+
```

### その他の状態

- 項目が空（重さ未入力など）: その行を表示しない。
- 写真がない: 写真の枠に「写真なし」の表示。
- 読み込み失敗: 「表示できませんでした [戻る]」。
- 後で追加する機能の入口（「友達に見せる」など）は、この画面の下部に置く想定。今回は描かない。

### アクセシビリティ

- 見出し: 魚種 = h1。ランドマーク: header（戻る）／main（写真と項目）。キーボード操作の入口: 最初のフォーカスは「戻る」。写真の代替テキストは魚種・サイズ・場所を含める。

## 後の機能の入口（描かない・置き場所だけ）

| 機能（intent-backlog） | 入口の想定位置 |
|------------------------|----------------|
| PU-2 グループとメンバー | S1 のヘッダー右にメニュー（グループ名の表示・招待） |
| PU-3 タイムライン共有 | S1 がそのままタイムラインになる（全員分が並ぶ）。切り替えは S1 上部のタブ「自分／みんな」 |
| PU-4 ポイントの地図 | S1 の下部に「一覧／地図」の切り替え |
| PU-5 位置共有 | 地図画面内 |

## Assumptions & Open Questions

- 登録時の必須項目は未確定（写真だけ必須か、魚種も必須か）。要件整理で決める。[assumption]
- 一覧・詳細に表示する「日付」は、登録した日をアプリが自動で記録する前提で描いている。scope-document の未確定事項と同じ。[assumption]
- 編集・削除がないため、誤登録の直し方がない。最小範囲の後に PU-1 へ追加するか、要件整理で判断する。[assumption]
