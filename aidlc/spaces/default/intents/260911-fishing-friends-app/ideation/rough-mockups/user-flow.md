## Flow 1: 釣り場で釣果を登録する（主要な流れ）

- Flow: 釣果を登録する
- Persona: 自分（釣りをしている本人）
- Trigger: 魚が釣れた
- Steps:
  1. S1 一覧 -> (＋) をタップ -> S2 登録が開く
  2. S2 登録 -> 「カメラで撮る」をタップ -> カメラが起動し、撮影した写真がプレビューに入る
  3. S2 登録 -> 魚種・サイズ・重さ・場所を入力 -> 各欄に値が入る
  4. S2 登録 -> 「保存する」をタップ -> 保存され、S1 一覧に戻る。登録した1件が先頭のカードに表示される
- Success outcome: S1 の先頭に、いま撮った写真のカードが見える
- Error paths:
  - 入力に不正な値（サイズに文字など） -> その欄の下に文言で指摘 -> 直して再度「保存する」
  - 保存に失敗 -> 画面上部に失敗の表示、入力内容は保持 -> もう一度「保存する」
  - 入力途中で「戻る」 -> 「入力を破棄しますか？」 -> 破棄して S1 へ／キャンセルして続ける

```
[S1 一覧] --(＋)--> [S2 登録] --撮影--> [S2 写真あり] --入力--> [S2 入力済み]
                                                                    |
                                                          --保存する-->
                                                                    |
                                                          [S1 一覧（先頭に新しい1件）]
```

<!-- Text fallback: 一覧から登録画面へ、撮影と入力の後に保存すると、一覧の先頭に新しい釣果が表示される。 -->

## Flow 2: 友達に釣果を見せる（intent-statement の成功の姿）

- Flow: 釣果を見せる
- Persona: 自分（スマホを友達に見せる）
- Trigger: 釣行中・釣行後に「見て」と見せる
- Steps:
  1. S1 一覧 -> スクロール -> 今日の釣果のカードが並んで見える
  2. S1 一覧 -> カードをタップ -> S3 詳細で大きな写真と項目が見える
  3. S3 詳細 -> 「戻る」 -> S1 一覧に戻り、別のカードを開ける
- Success outcome: 友達が画面上で釣果の写真と魚種・サイズ・場所を確認できる
- Error paths:
  - 詳細の読み込み失敗 -> 「表示できませんでした [戻る]」 -> S1 に戻る

```
[S1 一覧] --カードをタップ--> [S3 詳細] --戻る--> [S1 一覧]
```

<!-- Text fallback: 一覧のカードから詳細を開き、戻るで一覧に戻る往復。 -->

## Flow 3: 初めて開く（空の状態）

- Flow: 初回起動
- Persona: 自分
- Trigger: アプリを初めて開く
- Steps:
  1. S1 一覧（空の状態） -> 「まだ釣果がありません」と「釣果を登録する」ボタンが見える
  2. S1 -> 「釣果を登録する」をタップ -> S2 登録（Flow 1 の手順2以降へ）
- Success outcome: 最初の1件が登録され、S1 が通常状態になる
- Error paths: Flow 1 と同じ

## 後の機能との接続（intent-backlog の PU-2〜PU-5）

- PU-2 グループ参加: S1 のメニューから「招待リンクを作る／招待コードで参加」。
- PU-3 タイムライン: S1 に「自分／みんな」の切り替えを足し、「みんな」で友達の釣果も並ぶ。Flow 2 が「見せる」から「見合う」に変わる。
- PU-4 ポイントの地図: S1 に「一覧／地図」の切り替えを足す。S2 の場所入力は、地図のピンから選べるようになる。
- PU-5 位置共有: 地図画面の中で「今いる場所を共有」を押す。
